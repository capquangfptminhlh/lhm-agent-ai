# Contributing to LHM Agent OS

Contributions, forks and pull requests are welcome under the MIT license.

1. Create a fork and feature branch.
2. Do not commit keys, customer information, private account data or generated databases.
3. Install dependencies with `python -m pip install -r requirements.txt` and run `python -m unittest discover -s tests -v`.
4. Include tests for tool adapters, state transitions and permission controls.
5. Open a pull request summarizing changes and known limitations.

**Public repository does not mean everyone can push to its default branch.** Contributors use forks/pull requests; the maintainer retains merge permissions.
