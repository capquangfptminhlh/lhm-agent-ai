Đầu mục Agent và tool phù hợp

Đây là danh mục đề xuất tích hợp, KHÔNG đồng nghĩa repo đã được triển khai.

Cách vận hành tiết kiệm

✓ Một bộ não DeepSeek, không nhân bản model cho từng nhân viên
✓ Một Tool Registry điều phối nhiều hệ thống
✓ API đọc có thể chạy không cần duyệt (theo quyền)
✓ API ghi ra bên ngoài luôn chờ người phê duyệt
✓ Không tự động gửi lại khi timeout có thể đăng trùng
✓ Dùng Postiz thay vì tự phát triển 10 API mạng xã hội
✓ Activepieces để nối ứng dụng còn thiếu
✓ Định kỳ kiểm tra kết quả, lưu URL và đối soát

Các mốc tích hợp

P0: Postiz + WordPress + Activepieces. P1: CRM, support, research, Ads analytics. P2: ERP, nhân sự, media, nurture. P3: hợp đồng và ký số.

Hạn chế hiện tại: tất cả kết nối ngoài đang dùng một cấu hình server cho một workspace pilot; sản phẩm SaaS phải có OAuth và credential vault riêng cho mỗi khách hàng.

Repo và dịch vụ tích hợp theo nghiệp vụ

Trạng thái “Đã cấu hình” chỉ xác nhận có biến môi trường; không thay thế kiểm tra quyền API thật.

Đăng bài Social qua Postiz

Chỉ làm việc với tài khoản đã kết nối qua Postiz; Facebook Page, Instagram, TikTok, YouTube... yêu cầu quyền và định dạng khác nhau.

Chỉ tải lên Postiz, chưa tạo bài đăng.

Instagram bắt buộc có media. TikTok/YouTube yêu cầu cấu hình nâng cao trên Postiz; giao diện này chưa tạo các thiết lập đó tự động.

Website và các workflow khác

Chưa có API key hoặc quyền OAuth: có thể lập yêu cầu nhưng không chạy được bên ngoài. Lệnh chỉ được gửi khi người dùng bấm duyệt rồi bấm thực hiện.
